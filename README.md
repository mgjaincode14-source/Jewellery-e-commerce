# PP Collections 💍

An e-commerce frontend project built using React.

## ✨ Features
- Product categories (Necklace, Bangles, Earrings)
- Responsive UI design
- Login & Signup pages
- Clean card-based layout
- Add new product page UI

## 🛠 Tech Stack
- React.js
- JSX
- CSS
- Local Storage (frontend storage)

- Authentication system
- Admin dashboard
